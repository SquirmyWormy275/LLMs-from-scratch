# Independent projects and extensions

**Status:** no independent projects have been selected or implemented here yet.

This area is for projects you choose to develop beyond a chapter exercise, including applications, extensions, or investigations that draw on the books.

Create one folder per project when there is a real question or goal to work on. Keep the source, tests, project notes, and small result artifacts in that folder.

## What a future reviewer should be able to find

- The problem you chose and why it matters.
- Your contribution and the material you reused.
- The design decisions you made.
- Reproducible setup and run instructions.
- Relevant tests and evidence for measured claims.
- Tradeoffs, limitations, and remaining work.

You supply the technical content. The [workspace workflow](../../docs/WORKFLOW.md) describes how to make a finished project discoverable from the root README without duplicating it.

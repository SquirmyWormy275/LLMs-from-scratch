# LLM book exercise checklist

Track the numbered exercises in Sebastian Raschka's [*Build a Large Language Model (From Scratch)*](https://livebook.manning.com/book/build-a-large-language-model-from-scratch). This is a progress index, not a copy of the exercise prompts or a record of completed work. Use the book text for each prompt; the companion notebooks contain chapter code but do not reproduce the numbered exercise statements.

All boxes start unchecked. When you decide an exercise is done, change `[ ]` to `[x]` and commit that update with your work. Chapter 1 has no numbered exercises. The four Appendix A exercises are listed separately because that appendix is optional background material.

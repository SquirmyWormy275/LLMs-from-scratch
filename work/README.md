Create a folder when you begin an actual piece of work. Use a short descriptive name, such as a chapter number plus its topic, or the name of an independent project. Keep that item's code, tests, notes, and results together.

## Make each contribution understandable

Each work item's README should identify:

- **Status:** Planned, In progress, or Ready to review.
- **Contribution:** what the owner implemented or investigated.
- **Origin:** an implementation from the book's explanation, a reproduction, an adaptation of cited code, or an independent extension.
- **Evidence:** actual run commands, relevant checks, and recorded results when available.
- **Limits:** what is unfinished, uncertain, or not yet evaluated.

These are prompts for the owner's own writing. Do not invent answers or turn imported examples into personal results. Placing copied code under work/ does not change its authorship.
